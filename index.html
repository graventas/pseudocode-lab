Tab Jejak mencatat setiap langkah program (nilai variabel, hasil kondisi, putaran perulangan); klik satu baris jejak untuk menyorot nomor barisnya di editor. Terjemahan Python dan Go dibuat otomatis saat kamu mengetik. Pada program ber-kamus, tipe Go diambil dari kamus. Tanpa kamus, Go memakai tebakan tipe sederhana, jadi periksa dulu sebelum dijalankan.


Referensi sintaks

program Judul             (bentuk terstruktur)
kamus
    a, b : integer        tipe: integer, real, string, boolean, char
algoritma
    a <- 1                atau  a = 1  atau  a ← 1
    input(a, b)           output(a, b)
endprogram

Tanpa program/kamus (gaya bebas) juga boleh:
x <- 5   atau   x = 5          isi variabel
PRINT a, b                       (TAMPILKAN / CETAK)
INPUT x                          (BACA) angka otomatis dikenali
IF k THEN ... ELSE IF k THEN ... ELSE ... END IF
WHILE k DO ... END WHILE
FOR i FROM 1 TO 10 STEP 2 ... END FOR
FOR EACH x IN daftar ... END FOR
REPEAT ... UNTIL k
FUNCTION f(a, b) ... RETURN a + b ... END FUNCTION

Bawaan   : INT FLOAT STR ABS ROUND SQRT MAX MIN UPPER LOWER
